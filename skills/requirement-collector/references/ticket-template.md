# Jira draft ownership

This compatibility reference has no separate template. Read [Jira Ticket Supporter](../../jira-ticket-supporter/SKILL.md) and use its draft-only path and current content rules. Requirement Collector owns approved requirements and coverage, not ticket formatting. This skill never publishes or mutates Jira. If creation is separately authorized, hand the approved requirements and scope to Jira Ticket Supporter; only that owner executes and verifies the write.
